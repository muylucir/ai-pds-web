# 채팅 활동 인디케이터 설계 (소규모)

날짜: 2026-07-22
상태: 승인됨

문제: 턴 진행 중 시각적 피드백이 없어 멈춘 것처럼 보인다. (1) 스트리밍 대기
문구("AI가 작성 중…")가 정적 텍스트, (2) 질문 생성·문서 작성 같은 도구 활동
(status 이벤트)이 접힌 "추론 과정" 아코디언 안에만 쌓여 화면에 변화가 없음.

## A. 타이핑 인디케이터

- `AiMessage`: 스트리밍 중 텍스트가 비어 있을 때 정적 문구 대신 점 3개 bounce
  애니메이션(CSS `animate-bounce` + `animation-delay` 스태거). 접근성:
  래퍼에 `aria-label="AI가 작성 중"` 유지.

## B. 라이브 활동 라인

- 턴 진행 중(item.streaming) trace의 **마지막 status 항목**을 말풍선 하단에
  상시 한 줄 표시 + 펄스 점 애니메이션. 도구명 → 한글 매핑
  (`activityLabel(text)` 헬퍼, 같은 파일):
  - ask_questions → "질문을 준비하고 있어요…"
  - file_write, file_append → "문서를 작성하고 있어요…"
  - file_read → "자료를 확인하고 있어요…"
  - report_stage → "진행 상황을 기록하고 있어요…"
  - submit_document → "문서를 제출하고 있어요…"
  - 그 외 → `"{도구명} 실행 중…"`
- file_changed trace는 활동 라인 대상 아님(status만). 스트리밍 종료 시 라인
  제거 — 이력은 기존 "추론 과정" 아코디언에 그대로.
- 범위: `AiMessage.tsx` + 테스트. 스트림 훅/백엔드 무변경.

## 테스트

- 스트리밍+빈 텍스트 → 타이핑 인디케이터(aria-label) 렌더, 정적 문구 제거.
- 스트리밍+status trace 존재 → 매핑된 활동 라인 표시(마지막 status 기준).
- 스트리밍 종료 → 활동 라인 없음. 알 수 없는 도구명 → 폴백 문구.
