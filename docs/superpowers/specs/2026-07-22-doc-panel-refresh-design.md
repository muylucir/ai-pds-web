# 문서 패널 리프레시 버튼 설계 (소규모)

날짜: 2026-07-22
상태: 승인됨

워크스페이스 문서 패널(WorkspaceDocPanel) 헤더의 콤보박스 옆에 현재 문서
리프레시 버튼을 추가한다.

- 위치: 드롭다운과 버전 배지 사이. `↻` 아이콘 버튼, `aria-label="문서 새로고침"`.
- 동작: 클릭 시 현재 문서 내용(`content.reload()`)과 산출물 목록
  (`artifacts.reload()`)을 함께 재조회 — 문서만 갱신하면 방금 생성된 다른
  문서가 드롭다운에 안 보이므로 목록도 함께.
- 상태: `content.loading` 동안 disabled(연타 방지). 문서가 없는 빈 상태에서는
  버튼을 렌더하지 않는다.
- 범위: `WorkspaceDocPanel.tsx` 단일 파일 + 테스트. `useAsync`가 이미 `reload`를
  노출하므로 훅/백엔드 변경 없음.
- 테스트: 클릭 → 문서/목록 재fetch 발생(MSW 카운터), 빈 상태에서 버튼 미표시,
  로딩 중 disabled.
