IDEA TO EVIDENCE

좋은 아이디어보다 먼저 필요한 것은
확인할 수 있는 가설입니다

“AI로 무엇을 만들까?”에서 시작하지 않습니다. 누구의 어떤 문제가 중요한지, 현재 방식은 왜 부족한지, 무엇을 보여주면 방향을 판단할 수 있는지부터 함께 정리합니다.

01

고객 관점의 문제 정의

대상 사용자, 현재 대안, 핵심 Pain Point를 한 문장으로 정리합니다.
02

검증할 아이디어 하나

가치, 실행 가능성, 사용자 영향을 기준으로 후보를 좁힙니다.
03

직접 체험하는 프로토타입

AI가 만든 명세를 바탕으로 핵심 사용자 흐름을 실제 화면으로 확인합니다.
04

바로 공유할 검증 설문

프로토타입 링크와 함께 보내고, 응답을 다음 의사결정의 근거로 남깁니다.

검증된 방법론을 기반으로

임의로 만든 커리큘럼이 아닙니다

이 워크숍은 AWS가 공개한 AI-Driven Product Life Cycle (AI-PLC)의 Discovery 절차를 기반으로 합니다.

AI-PLC의 체계는 그대로,
개발자 도구의 장벽은 없앴습니다.

Codex·Claude Code·Kiro 같은 코딩 어시스턴트를 참가자가 직접 설치하거나 조작할 필요가 없습니다.

✓ 별도 AI 코딩 도구 설치 없음
✓ 터미널 명령어나 마크다운 파일 편집 없음
✓ 질문, 문서 리뷰, 프로토타입 실행까지 브라우저에서

Pathfinder가 개발자 도구와 파일 편집이 필요했던 절차를 브라우저 기반 질문 위저드와 문서·프로토타입 화면으로 제공합니다. 방법론이 공개되어 있으므로 워크숍이 끝난 뒤에도 조직 안에서 같은 흐름을 이어서 활용할 수 있습니다.

워크숍 이후, 실제 빌드로 이어갈 수 있습니다
