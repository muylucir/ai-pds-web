# 비즈니스 컨텍스트 — 입력 방식 선택

Path A(페인포인트 → PR/FAQ)를 선택하셨습니다. 페인포인트를 파고들기 전에, 그 페인포인트가 놓인
**비즈니스 컨텍스트**를 먼저 확정합니다. 같은 "삭감 대응"이라도 병원 심사청구팀인지, 보험사
심사팀인지, 이들을 대행하는 청구대행(RCM) 업체인지에 따라 문제의 주인과 돈의 흐름이 달라지고,
그에 따라 제품의 형태도 완전히 달라지기 때문입니다.

Envision이 반드시 채워야 하는 컨텍스트 영역은 다음 5가지입니다.

1. 어떤 산업/업무 도메인의 제품인가 (예: 병원 원무·심사청구, 보험사 지급심사, RCM 대행)
2. 그 도메인에서 조직의 현재 상태는 어떤가 (조직 규모, 청구 물량, 사용 중인 시스템)
3. 오늘 겪고 있는 주요 어려움은 무엇인가 (삭감률, 이의신청 처리 시간, 재작업 부담 등)
4. 주요 고객/대상 사용자는 누구인가 (심사청구팀 담당자, 팀장, 진료과 의료진 등)
5. 지금은 그 문제를 어떤 방식으로 해결하고 있는가 (엑셀 관리, 자체 개발 시스템, 외부 솔루션, 수작업)

아래에서 이 5개 영역을 **어떤 방식으로 채울지**만 먼저 골라 주세요. 내용 자체는 선택하신 방식에
맞춰 다음 단계에서 수집합니다.

- A) 가장 빠릅니다. 아는 내용을 한 번에 쏟아내면 부족한 영역만 제가 골라 되묻습니다.
- B) 병원/보험사 소개 페이지처럼 공개된 정보로 조직 규모·진료과·사업 범위를 잡을 때 유용합니다.
  단 삭감률·처리 시간 같은 내부 수치는 공개 페이지에 없으므로 이후 보완 질문이 붙습니다.
  (보안 정책상 `https://` 공개 URL만 읽으며, 지정하신 URL 외에는 어떤 것도 읽지 않습니다.)
- C) B로 큰 틀을 잡고 A로 내부 사정을 덧붙이는 방식입니다. 가장 정확하지만 손이 조금 더 갑니다.
- D) 무엇을 말해야 할지 막막할 때 좋습니다. 5개 영역을 객관식 질문으로 나눠 드립니다.
