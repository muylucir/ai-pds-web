# Solution Analysis — QA TestCase Copilot

## PR/FAQ에서 도출한 솔루션 후보

PR/FAQ는 두 개의 핵심 역량을 담고 있습니다.

1. **정책 기반 TC 설계** — 흩어진 정책/기획 문서(Figma·Confluence·기획서)를 분석해
   고품질 TC 초안과 "확인 필요 문의사항"을 생성.
2. **Auto/Manual/휴먼체크 분류** — 명세화된 기준으로 각 TC의 자동화 가능 여부를 근거와 함께 분류.

## 분석: 단일 vs 복수

### 관점 1 — 단일 통합 솔루션 (권장)
두 역량은 순차 파이프라인으로 자연스럽게 연결됩니다.

```
+------------------+     +---------------------+     +------------------------+
| 정책/기획 문서    | --> | TC 초안 + 문의사항   | --> | Auto/Manual/휴먼체크    |
| (Figma/Confl 등)  |     | 생성                |     | 분류 (근거 포함)         |
+------------------+     +---------------------+     +------------------------+
```
- 장점: 하나의 흐름으로 검증 가능, "생성된 TC를 바로 분류"하는 실제 업무 순서와 일치.
- 단일 프로토타입으로 빠르게 가치 검증 가능.

### 관점 2 — 복수 분리 솔루션
- 솔루션 A: 정책 기반 TC 생성기
- 솔루션 B: TC Auto/Manual 분류기 (기존 TC 시트 입력)
- 장점: 각각 독립 도입/검증 가능. 분류기는 기존 TC 자산에 즉시 적용 가능.
- 단점: 두 개를 각각 우선순위화·프로토타이핑해야 함.

## 권고
**단일 통합 솔루션**으로 프로토타입 1종을 만들어 검증하는 것을 권장합니다.
(분류 기능만 먼저 쓰고 싶은 경우, 통합 프로토타입 내에서 "기존 TC 입력 → 분류" 진입점도 지원하도록 설계 가능.)
