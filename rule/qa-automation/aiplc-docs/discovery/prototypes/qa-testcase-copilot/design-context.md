# Design Context — QA TestCase Copilot

## 브랜드/톤
- 내부 QA 도구. 브랜드 URL 불필요.
- 톤: 실무 중심, 간결. 결과(TC 표)가 화면 주역이 되도록 정보 밀도 높은 데스크톱 레이아웃.

## 대상 기기/화면
- 데스크톱 브라우저 (와이드 테이블 편집에 적합).

## 핵심 UX 원칙
- **검토 우선**: AI 결과는 "초안"임을 명확히. 문의사항을 눈에 띄게 분리.
- **근거 투명성**: 각 분류에 근거를 펼쳐 볼 수 있게.
- **비단정**: 애매한 항목은 휴먼체크로 표시하고 이유 제시.
- **내보내기 친화**: 팀 포맷 CSV/XLSX로 바로 반출.

## 화면 흐름 (텍스트)
1. 입력: [정책 텍스트 붙여넣기] 탭 / [기존 TC 업로드] 탭
2. 실행 → 진행 상태
3. 결과: 좌측 TC 표(편집) · 우측 문의사항 패널 · 행별 분류근거 토글 · 상단 내보내기
